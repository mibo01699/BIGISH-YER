# BIGISH-YER: Comprehensive API Endpoints Documentation

This document serves as the technical reference for all backend micro-services operating within the BIGISH-YER Macroeconomic Stabilization matrix. All endpoints are designed for **Sandbox/Testnet-first validation** and do not claim any official Pi Network integration unless explicitly stated.

---

## 1. Global Security Headers (Mandatory)
Every HTTP request targeting a protected route must include the following identity verification headers (provided by the internal identity layer or a supported adapter):

- `x-user-id`: The unique hash identity of the authenticated user (internal system).
- `x-access-token`: The runtime security token generated by the internal auth service.
