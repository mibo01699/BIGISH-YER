# BIGISH-YER: Comprehensive API Endpoints Documentation

This document serves as the absolute technical reference for all backend micro-services operating within the BIGISH-YER Macroeconomic Stabilization matrix. All endpoints require strict compliance with the Pi Network v2.0 SDK sandbox protocol.

---

## 1. Global Security Headers (Mandatory)
Every HTTP request targeting a protected route must inject the following cryptographic headers verified by the Pi Browser sandbox:
- `x-pi-user-id`: The unique hash identity of the authenticated Pioneer.
- `x-pi-access-token`: The runtime security token generated by `window.Pi.authenticate()`.

## 2. Ledger Settlement & Clearing Modules

### `POST /api/yer/transfer`
Executes clearing balances and multi-token parallel settlement between humanitarian aid networks and point-of-sale systems.

* **Headers:** Global Security Headers + `Content-Type: application/json`
* **Request Payload Format:**
```json
{
  "piPaymentId": "pay_987654321_blockchain_ref",
  "senderYerWallet": "YER_AJYAL_SRC_01",
  "receiverPosWallet": "YER_GAV_POS_02",
  "amountYer": 1500.00,
  "memo": "Monthly civil salary stabilization subsidy"
}
```
* **Success Response (200 OK):**
```json
{
  "success": true,
  "message": "Clearing & Settlement executed successfully across macro-channels.",
  "ledgerIndex": 44982,
  "piBlockchainTxId": "pi_tx_hash_9988776655"
}
```
* **Error Responses:**
  - `401 Unauthorized`: Missing or compromised Pi identity signatures.
  - `409 Conflict`: Rejection triggered by `AntiDoubleDippingEngine.js` due to duplicate transaction IDs.
