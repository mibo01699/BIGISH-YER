# Contributing to BIGISH-YER Wallet 🇾🇪

Thank you for your interest in contributing to the decentralized smart wallet infrastructure for Yemen. We welcome all developers, economists, and Web3 enthusiasts to help us combat inflation and enhance local remittance tools.

## 🚀 How to Get Started
1. **Fork the Repository:** Click the "Fork" button at the top right of this page to create your own copy.
2. **Clone Your Fork:** Clone it locally or import it to your preferred cloud IDE (e.g., Replit).
3. **Explore Open Issues:** Check our issue tracker for tasks related to UI updates, Pi SDK verification, or security auditing.

## 🛠️ Development Guidelines
* Ensure code remains highly optimized and lightweight for low-bandwidth mobile environments in Yemen.
* Adhere strictly to secure cryptographic compilation guidelines when handling wallet protocols.
* Prioritize local Testnet validation before submitting production-ready code.

## 📬 Submitting a Pull Request (PR)
* Create a descriptive branch name (e.g., `feature/ui-optimization`).
* Commit your changes with clear messages (e.g., "Fix Pi Payment callback handler").
* Submit a Pull Request targeting the `main` branch. All submissions will be audited by the engineering leads.
